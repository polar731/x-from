服务端接口

接口对接已拆分到 assets/api.js，统一返回 { code, info, data }

POST /api/admin/form/create　创建表单（publish=true 直接发布）
GET /api/admin/form/list　表单列表（keyword/status/page/pageSize）
GET /api/admin/form/stats　数据概览
GET /api/admin/form/detail?formNo=　表单详情
POST /api/admin/form/publish?formNo=　发布表单
POST /api/admin/form/close?formNo=　关闭表单
GET /api/admin/form/submissions?formNo=　填写数据分页
GET /api/form/{formNo}　用户端获取表单
POST /api/form/submit　用户端提交数据
